# Security policy

Do not report exploitable skill behavior in a public issue. Use GitHub's private vulnerability
reporting feature for this repository.

Security-sensitive findings include digest bypasses, unsafe target validation, parameter injection,
revision rollback, unreviewed catalog publication, and skills that can send, delete, purchase,
transfer, install, or change account/security state.

The registry must never contain user prompts, contacts, messages, email bodies, destinations,
screenshots, accessibility trees, device identifiers, tokens, or credentials.
